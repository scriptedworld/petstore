# FR-7.9, Names

| ID | Requirement | |
|---|---|---|
| FR-7.9 | A name shall be one kind of instrument: asking for a counter under a measure's name, a measure under a counter's, or a measure with a different `keep` or `under` from its first, shall be refused with `StatsError`; asking again with the same configuration shall return the same measure. | [A] |
