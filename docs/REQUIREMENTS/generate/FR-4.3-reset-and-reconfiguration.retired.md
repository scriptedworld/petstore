# FR-4.3, Reset and reconfiguration

| ID | Requirement | |
|---|---|---|
| FR-4.3 | Stub shall allow return and exception behavior to be reconfigured and shall clear its complete call history on reset without changing behavior until explicitly reconfigured. | [A] |

Retired: a generated function cannot be reconfigured, only have its call history reset.
Superseded by FR-4.9.
