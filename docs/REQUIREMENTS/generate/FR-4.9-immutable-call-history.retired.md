# FR-4.9, Immutable call history

| ID | Requirement | |
|---|---|---|
| FR-4.9 | Every generated function shall record immutable invocation metadata in order before performing its configured behavior, expose the total call count, and allow its history to be reset without changing its behavior. | [A] |

Retired: Generated functions are disposable; creating another function replaces mutable history-reset behavior.
Superseded by FR-4.12.
